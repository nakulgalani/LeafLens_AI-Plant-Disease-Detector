About LeafLens AI

An AI-powered plant disease detection system that identifies diseases from leaf images and localizes the affected regions.

What it does

LeafLens AI combines two machine learning approaches to give a more complete diagnosis than either model alone. A convolutional neural network (CNN) classifies the overall disease category from the leaf image, while a YOLO object detector localizes the region of the leaf the model is focusing on, drawing a visible bounding box around it. Together, they provide both an answer and a visual explanation of where that answer comes from.

How it works

Upload→ Classify→ Detect→ Analyze→ Report

Technology stack

Python TensorFlow YOLOv8 Flask OpenCV ReportLab

A note on accuracy

LeafLens AI is a student/internship project intended to demonstrate a CNN + YOLO pipeline for plant disease detection. Predictions are generated automatically and should be treated as a supporting reference rather than a substitute for professional agronomic diagnosis, particularly for high-stakes crop decisions.
