The Models

Two models, two jobs: one classifies, one localizes. Here's how each was built.

📷 Live Camera — Multimodal Vision API

  • ProviderGroq (inference platform)
  • ModelQwen 3.6 27B (multimodal, vision-capable)
  • TrainingGeneral-purpose pretrained model — not custom-trained on PlantVillage
  • InputA single captured camera frame + a structured prompt
  • OutputJSON: plant, likely disease, qualitative confidence, severity, symptoms, recommendation
  • PurposeFast, general-purpose second opinion — separate from the CNN/YOLO pipeline

Why the Live Camera result looks different

The Live Camera feature deliberately uses a different visual style and a qualitative confidence label ("High" / "Moderate" / "Low") instead of a numeric percentage. This is intentional: the CNN and YOLO models were trained specifically on the PlantVillage dataset and their confidence scores are real calibrated probabilities from that training. The multimodal vision API is a general-purpose model that was never trained on this specific dataset — presenting its output identically to the CNN/YOLO results would imply a level of precision it doesn't actually have. Every Live Camera result is clearly labeled with which multimodal API and model produced it.

How the final result is combined

Both models run on every uploaded image. If they agree on the diagnosis, the combined confidence is boosted slightly to reflect that agreement. If they disagree, the result from whichever model reported higher confidence is used as the final diagnosis, and both individual predictions are still shown side by side so the disagreement is visible rather than hidden.
